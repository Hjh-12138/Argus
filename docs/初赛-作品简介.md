# Argus：AI 代码发布安全门禁

> 正文 499 字（不含标题与分隔），项目名约 16 字。

AI 编程加速交付，也放大了依赖幻觉、注入漏洞和 CI 漏测，LLM review 还会虚构证据。Argus 面向 AI 应用与平台工程团队，发布前把代码变更映射为可审计多 Agent 门禁。

核心方案：按依赖/架构/代码/安全/性能/鲁棒性/交付/攻击八类评估 Agent，已实现 Dependency、Code、Security、Delivery 四类并行检查不可变快照；Meta 核验 finding 的路径、行号、哈希与证据，拦截幻觉；Synth 确定性输出 pass/warn/block/unknown 与原子报告。以 AgentTeams v1.2.0-beta.1（Matrix、MinIO、Project Room）编排，运行 deepseek-v4-flash，八个 Nacos 锁定 Skill 固化检测规则与证据格式，代码不出网。

创新点：启发式调度先于模型、Meta 证据门禁、失败不伪装成功、数据飞轮自迭代。Apache-2.0 开源，开放 Skill schema 与三缺陷样例，可复用于合规等企业闭环。已有 headless CLI、六 Worker Demo 与评测数据（vulnerable 全 block、fixed 全 pass、幻觉被拦截）。
