# Argus：AI 代码发布安全门禁

AI 编程把交付周期从周压缩到小时，也放大了依赖幻觉、占位实现、注入漏洞和 CI 漏测进入生产的风险。Argus 面向 AI 应用开发团队，在每次代码变更发布前启动可运行、可验证、可审计的多 Agent 安全门禁。

系统以 AgentTeams v1.2.0-beta.1 为协同骨架：Dependency、Code、Security、Delivery 四个 Worker 并行检查不可变源码快照；Meta Worker 核验每条 finding 的路径、行号、源码哈希和 evidence，拦截幻觉；Synth Worker 只消费通过核验的机器工件，以确定性策略给出 pass、warn、block 或 unknown，并原子生成 JSON/Markdown 报告。核心能力封装为四个带 schema 和完整目录 digest 的可复用 Skill，通过 Controller-owned ZIP 路径分发到六个常驻 Worker。Project Room、Matrix 调度和 MinIO task DAG 提供真实协作与证据留存。

三缺陷 Demo 可稳定检出不存在依赖、SQL 字符串拼接注入、CI 未运行已有测试，并证明虚构文件行号的 finding 不会进入发布报告。当前已完成 headless CLI、六 Worker 编排、Skill 锁、Meta 证据门禁、确定性 release gate、原子报告和最小结构化 trace。项目采用 Apache-2.0，计划开放 Agent/Skill 接口、样例场景与评测方法，帮助团队复用“变更触发—多 Agent 协作—证据核验—发布决策”的安全闭环。
