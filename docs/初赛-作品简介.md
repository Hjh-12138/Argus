# Argus：AI 代码发布安全门禁

AI 编程加速交付，也放大了依赖幻觉、注入漏洞和 CI 漏测的风险。Argus 面向 AI 应用团队，在发布前建立可运行、可审计的多 Agent 安全门禁。

系统以 AgentTeams v1.2.0-beta.1 为协同骨架：Dependency、Code、Security、Delivery 四个 Worker 并行检查不可变快照；Meta Worker 核验 finding 的路径、行号、哈希和证据，拦截幻觉；Synth Worker 确定性给出 pass/warn/block/unknown 并生成报告。核心能力封装为八个带 schema 的 Nacos 锁定 Skill，Project Room、Matrix 和 MinIO DAG 留存协作证据。

三缺陷 Demo 可检出不存在依赖、SQL 拼接注入和 CI 未运行测试，并证明虚构行号被拦截。当前已完成 headless CLI、六 Worker 编排、Skill 锁、Meta 门禁、确定性 release gate、原子报告和结构化 trace。项目采用 Apache-2.0。
